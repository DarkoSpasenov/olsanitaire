INSTALLATION
1. Envoyer tous les fichiers à la racine du site / FTP.
2. Vérifier que le domaine pointe bien vers le dossier contenant index.html.
3. Le formulaire utilise "mailto:" et ouvre l'application e-mail du visiteur. Pour une réception directe sans ouvrir l'application e-mail, remplacer ensuite par Formspree ou un formulaire serveur.
