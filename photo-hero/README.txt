PHOTO PRINCIPALE DU HERO

Ce dossier contient la photo principale affichée en haut de la page d'accueil.

Pour modifier cette photo :
- remplacez le fichier existant par votre nouvelle image en gardant le même nom ; ou
- supprimez/ajoutez des images dans ce dossier.

Le site chargera automatiquement la première image du dossier (ordre alphabétique/numerique).

Conseils :
- privilégiez une image horizontale ;
- format recommandé : .webp ;
- largeur recommandée : 1200 px ou plus.

Exemple de noms :
- 01-ma-photo.webp
- 02-autre-photo.webp
