DOSSIER DES PHOTOS — « NOS RÉALISATIONS »

Tu peux gérer le slider directement depuis ce dossier.

POUR REMPLACER UNE PHOTO
- Remplace simplement le fichier en gardant exactement le même nom.
- Exemple : remplace « 03-chauffage-au-sol.webp » par une nouvelle image portant le même nom.

POUR AJOUTER UNE PHOTO
- Dépose simplement une nouvelle image dans ce dossier.
- Formats acceptés : .jpg, .jpeg, .png, .webp, .avif
- Le site l'ajoutera automatiquement au slider.
- Pour choisir l'ordre, commence le nom par un numéro :
  01-photo.webp
  02-photo.webp
  03-photo.webp
  etc.

POUR SUPPRIMER UNE PHOTO
- Supprime simplement le fichier image du dossier.

IMPORTANT
- Ne supprime pas « liste.php » : c'est ce fichier qui permet au site de détecter automatiquement les photos présentes dans ce dossier.
- « README.txt » n'est pas affiché sur le site.
